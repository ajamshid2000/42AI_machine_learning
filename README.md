# 42AI Machine Learning Exercises

This repository contains exercises from the 42AI Machine Learning curriculum, organized into modules covering various topics in machine learning.

## Modules

### Module 00: Statistics and Basic Operations
- **ex00**: TinyStatistician - A class for basic statistical computations (mean, median, quartile, percentile, variance, standard deviation)
- **ex01**: Tools - Utility functions for data manipulation
- **ex02**: Prediction - Basic prediction functions
- **ex03**: Plot - Data visualization utilities
- **ex04**: Vec Loss - Vectorized loss functions
- **ex05**: Other Losses - Additional loss function implementations
- **ex06**: Plot - Advanced plotting functions
- **ex07**: Matrix - Matrix operations

### Module 01: Linear Regression
- **ex00**: Gradient - Gradient descent implementation
- **ex01**: Vec Gradient - Vectorized gradient descent
- **ex02**: Fit - Model fitting functions
- **ex03**: My Linear Regression - Custom linear regression class
- **ex04**: Linear Model - Linear regression with data
- **ex05**: Z-Score - Z-score normalization
- **ex06**: Minmax - Min-max scaling

### Module 02: Advanced Machine Learning
- **ex00**: Prediction - Advanced prediction methods
- **ex01**: Prediction - Specialized prediction functions
- **ex02**: Loss - Loss function implementations
- **ex03**: Gradient - Advanced gradient computations
- **ex04**: Fit - Model fitting algorithms
- **ex05**: MyLinearRegression - Enhanced linear regression
- **ex06**: Multivariate Linear Model - Multi-variable linear regression
- **ex07**: Polynomial Model - Polynomial feature engineering
- **ex08**: Polynomial Train - Training polynomial models
- **ex09**: Data Spliter - Data splitting utilities
- **ex10**: Benchmark Train - Model benchmarking and training

## Requirements

- Python 3.x
- NumPy
- Matplotlib (for plotting exercises)
- Pandas (for data handling)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/42AI_machine_learning.git
cd 42AI_machine_learning
```

2. Install dependencies:
```bash
pip install numpy matplotlib pandas
```

## Usage

Each exercise contains Python files with implementations and test cases. Run the files directly or use the included test suites:

```bash
python -m unittest module00/ex00/TinyStatistician.py
```

## Learning Objectives

This curriculum covers:
- Statistical analysis and data preprocessing
- Linear regression and gradient descent
- Polynomial regression and feature engineering
- Model evaluation and validation
- Data visualization techniques
